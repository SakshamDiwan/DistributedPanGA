\subsection{Comparison with FastGA}\label{sec:disc:fastga}

On the yeast and primate datasets,
DistributedPanGA is faster than FastGA at every equal core count tested. Both tools run FastGA's alignment code, so the
difference comes from how the work is split. On yeast7 and primates4.chr6
the gap widens with cores. On primates14.chr6 it narrows, from 1.9$\times$
at 16 cores to 1.3$\times$ at 64, because both tools stop improving after 32
cores: from 32 to 64, FastGA speeds up by 1.04$\times$ and DistributedPanGA
not at all. This fits a limit both share: FastGA, like DistributedPanGA,
aligns each contig pair on a single thread, so the most expensive pair
bounds both.

On one node, DistributedPanGA with 16 ranks is 1.1$\times$ faster than
FastGA's fastest time (64 threads); on two nodes it is 1.3$\times$ faster. Four nodes add nothing,
for the reason in Section~\ref{sec:disc:small}: until the work is assigned more evenly, more nodes do
not shorten the slowest rank.
